# Design handoff (Google Stitch)

Reference material only; nothing here is imported by the app.

- `DESIGN.md` — the design system as built (colors, typography, spacing). Started as a Stitch export; now maintained by hand to match the code, so update it when tokens change.
- `screens/<name>.html` — per-screen HTML/Tailwind from Stitch's code panel.
- `screens/<name>.png` — screenshot of each screen (add mobile variants if they exist).
- `MOTION.md` — what animates on load, on scroll, and between sections/pages. Stitch doesn't export this.
